Design System

Reference for color, type, spacing, components, and motion across the site. Two-color actions, the five-stop format field, violet-to-magenta identity, pill-shaped chips, Geoapify location suggestions, and Sora UI typography are now the live system.

Usage Rules
  1. Use approved gradient sequences only. Choose the complete five-stop ramp or one of the three focused variants; do not invent intermediate colors.
  2. The full five-stop ramp belongs to the open-format field. It carries the complete palette inside a bounded panel with visible black page gutters.
  3. Primary buttons use Ultraviolet to Violet. Preserve the order and use Ink for every button label.
  4. The brand mark uses Violet to Magenta. Navigation, hero, footer, and documentation all reference the same two-color SVG asset.
  5. The favicon stays static. It uses the original brush K and the complete five-stop ramp; favicon animation is not consistent across browsers, so motion belongs to an in-page logo treatment instead.
  6. Selected chips are solid Violet. Gradients never indicate chip selection.
  7. Solid accents are one ramp stop per element. For repeated items — genre tags, category badges — cycle stops in hue order so the set reads as designed, not randomized.
  8. Text on any ramp color is always Ink. Never Fg, never white, whether the color is a gradient or a solid fill.
  9. Black and white are the only neutrals. Use opacity for hierarchy and dividers instead of introducing gray or tinted-neutral colors.
  10. Body and UI copy stay neutral. The ramp is for accents, not for paragraphs or nav text.
  11. A new stop extends the formula — oklch(0.78 0.19 H) at a new H, ~20° from its neighbors — rather than an unrelated color dropped in.

Usage Rules
  1. Anton is display-only — headlines and stat numbers, always uppercase. It has no real lowercase reading design; don't set body copy in it.
  2. Sora carries every paragraph. Sentence case, never all-caps.
  3. Sora is UI chrome — nav, buttons, chips, captions. Uppercase and tracked for short labels, sentence case for longer strings.
  4. Two typefaces, no more. A third needs a real reason, not a one-off.
  5. Multi-line headings get balanced wrapping so they don't end on an orphan word.

One width cap, one responsive breakpoint, one seam technique for grids. Repetition here is the point.

The five-color panel stops short of every page edge: 16px gutters on small screens, 48px at the content breakpoint, a 1440px maximum width, and square corners.

Grid seams

1px gap on a tinted background, not per-card borders or shadows — the same trick behind the events grid and capabilities gallery. The stats strip keeps visible top and bottom rules so its outer grid is complete.

Usage Rules
  1. Every section's content sits inside Container (1440px, centered). Most section surfaces can extend full bleed; the open-format field is the intentional exception and uses a bounded, square-edged panel.
  2. Container stays a dumb wrapper. No position, transform, opacity, or z-index classes, ever — any of those creates a stacking context and breaks layered sections like the hero.
  3. 900px is the one breakpoint most sections need. Don't add a second one without a real reason.
  4. Dividers are a single hairline, 10% opacity foreground. No shadows, no heavier rules.
  5. Card collections share seams via a 1px gap and tinted grid background, not individual borders or drop shadows.
  6. Stat strips keep both outer horizontal rules. The top and bottom hairlines frame the repeated cells; internal borders only divide them.

Afrobeats

Colour means interactive. Every chip is a fully rounded pill, but the two families are semantic, not decorative. Interactive chips are the only ones a user can act on — currently just the budget selector — and carry Violet with a selected state. Static chips are read-only labels: capability lists and the genre row. They are monotone so nothing suggests a control, and their border is deliberately faint so a long row reads as one texture rather than as ten buttons. Pick static or static-light by the surface behind the chip, not by meaning. A static chip never gains a hover, focus, or selected state — if it needs one, it is interactive.

Icons are decorative. Adjacent text always carries the meaning, so every icon is aria-hidden and none receives a label. The One Icon Library Rule: a second icon library is forbidden — mixing sets puts two optical grids and two stroke weights on one page.

Media Strip

Five 3:4 tiles, each pulled 28px onto the one before it. This is the only place in the system where surfaces overlap — everywhere else keeps strict 1px seams and flat planes. It also earns the one shadow permitted outside the calendar popover: without a cast edge the overlap is geometrically correct and visually invisible.

third tile shown active · overlap 28px · rest: grayscale(1) + brand gradient at mix-blend-mode: color, 0.85

Filter. Rests fully desaturated (grayscale(1)) under the brand gradient at mix-blend-mode: color, opacity 0.85, which takes hue from the overlay and luminance from the frame beneath — a true duotone rather than a wash. On hover, focus or playback the media returns to grayscale(0) and the overlay fades to 0, snapping the tile to its real colour. Tiles carry no visible caption; each is a button with an aria-label. Playback. Every clip is muted, looping, playsInline, preload="none" with a poster. Fine pointer plays on hover and focus, because hover-only playback is unreachable by keyboard. Coarse pointer plays the most-visible clip, one at a time. Reduced motion never autoplays — the poster stands in.

Motion

05

Every reveal on the site runs this exact curve.

Reveal
opacity: 0 → 1
translateY: 16px → 0
duration: 0.6s
ease: cubic-bezier(.16,1,.3,1)
trigger: viewport, once
Usage Rules
  1. Only transform and opacity animate. Nothing that triggers layout — width, height, top, left.
  2. Every animation has a static fallback for prefers-reduced-motion — never hide content for those users, just skip the motion.
  3. The beat-synced pulse and the WebGL laser rig belong to the hero. They're a signature moment, not a pattern — a second beat-synced element competes with the first.
  4. Chrome that appears on scroll (like the nav background) stays absent at rest everywhere that pattern gets reused.

Accessibility

06

Non-negotiable, not aspirational.

Usage Rules
  1. 4.5:1 minimum contrast for body text against its background; large text and UI components hold 3:1.
  2. Every interactive element shows a visible focus state. Never remove the outline without shipping a replacement.
  3. Touch targets are 44×44px minimum. Pad the hit area — don't rely on the visible glyph size.
  4. prefers-reduced-motion is honored everywhere motion appears, not only in the hero.
